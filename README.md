# No Limits Launcher

Launcher Minecraft desktop multipiattaforma, in sviluppo.

## Stato
- Interfaccia desktop PySide6
- Ricerca modpack Modrinth
- Registro locale delle istanze
- Autenticazione Microsoft in integrazione
- Installazione modpack, loader, avvio Minecraft e CurseForge ancora in sviluppo

## Requisiti
Python 3.11+

Questo progetto è indipendente da Nuovo Ordine.
